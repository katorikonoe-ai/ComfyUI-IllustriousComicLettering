# Changelog

## 1.1.0 - 2026-09-02

- Added `bubble_width_limit`, `tail_length`, `tail_width`, and `bubble_top_offset` controls.
- Shortened and narrowed the default tail to reduce overlap with faces and hair.
- Changed the default font to regular DejaVu Sans for a cleaner manga-lettering appearance.
- Preserved the original node type so existing workflows can be upgraded in place.

## 1.0.0 - 2026-08-27

- Initial `IllustriousComicLettering4Panel` node.
- Deterministic four-panel bubbles, automatic wrapping and font fitting.
- Bubble-mask output, example workflow, demonstration image, and local test.
