# Contributing

Bug reports and focused pull requests are welcome.

1. Clone this repository into `ComfyUI/custom_nodes`.
2. Install `requirements.txt` in ComfyUI's Python environment.
3. Restart ComfyUI and confirm the node appears under `Illustrious Comic/Lettering`.
4. Run `python test_node.py` before opening a pull request.

When reporting a runtime problem, include the ComfyUI version, operating system, Python version, complete traceback, input dimensions, and a minimal workflow JSON. Do not upload private checkpoints or LoRAs.
